# AURA — Autonomous Unified Revenue Analytics

A production-style data analytics platform that automatically processes
business data through ETL, statistical analysis, ML, anomaly detection,
forecasting, and AI-powered explanation.

## Status
Under active development

## Architecture
- **Orchestration:** n8n
- **Database:** PostgreSQL + DuckDB
- **Processing:** Python (Pandas, Scikit-learn, SciPy)
- **BI:** Power BI Desktop
- **Local AI:** Ollama
